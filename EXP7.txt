EXPERIMENT 7 - DATA ANALYSIS AND DATA VISUALIZATION USING R Dataset:
Student Academic Performance

============================================================ PART 1 -
INSTALLATION AND STARTING R
============================================================

A. Ubuntu: Update package list

sudo apt update

B. Install R

sudo apt install r-base

C. Check R version in Ubuntu terminal

R –version

D. Start R console

R

E. Check version inside R console

version

F. Print R version

print(R.version.string)

NOTE: The command -version is not an R command. Use version inside the R
console. RStudio is an IDE for writing and running R scripts. Download
RStudio Desktop from: https://posit.co/download/rstudio-desktop/

============================================================ PART 4 -
DATA ANALYSIS
============================================================

QUERY 1 - DISPLAY STRUCTURE OF DATASET

str(student_data)

Purpose: Displays the number of observations, variables, column names
and data types.

QUERY 2 - SUMMARY OF DATASET

summary(student_data)

Summary of Final Marks only:

summary(student_data$Final_Marks)

Purpose: Displays minimum, first quartile, median, mean, third quartile
and maximum.

QUERY 3 - MEAN, MEDIAN AND STANDARD DEVIATION

A. Mean of Final Marks

mean(student_data$Final_Marks)

Expected result: 76.66667

B. Median of Final Marks

median(student_data$Final_Marks)

Expected result: 78

C. Standard Deviation of Final Marks

sd(student_data$Final_Marks)

Expected result: 13.21615

QUERY 4 - MINIMUM AND MAXIMUM FINAL MARKS

A. Maximum marks

max(student_data$Final_Marks)

Expected result: 94

B. Minimum marks

min(student_data$Final_Marks)

Expected result: 50

QUERY 5 - GENDER COUNT

table(student_data$Gender)

Expected result: Female 7 Male 8

============================================================ PART 6 -
ALL IMPORTANT R COMMANDS
============================================================

data.frame() - Creates a data frame. c() - Combines values into a
vector. print() - Displays data. str() - Displays dataset structure.
summary() - Displays statistical summary. mean() - Calculates mean.
median() - Calculates median. sd() - Calculates standard deviation.
max() - Finds maximum value. min() - Finds minimum value. table() -
Counts frequencies. barplot() - Creates a bar chart. hist() - Creates a
histogram. plot() - Creates a scatter plot. pie() - Creates a pie chart.
version - Displays R version information.
